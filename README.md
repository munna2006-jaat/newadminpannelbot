## 🚀 1. Admin Server Setup & Run

The admin server runs with native Node.js (requires Node >= 22) and SQLite with **ZERO external npm package installations** needed!

```bash
cd "admin-server"
node server.js
```

- **Admin Web Dashboard:** Open `http://localhost:3000` in any web browser.
- **Master Admin Password:** `Admin@AcePro2026`

### Admin Features:
1. **Create New Licenses:** Generate Username, Password, Validity in Days, and optional pre-assigned P2P Account.
2. **Instant Remote Kill-Switch (ON/OFF Button):**
   - Click the green `🟢 ON (ACTIVE)` button on any user to turn it `⛔ OFF (SUSPENDED)`.
   - The user's phone / Kiwi browser / Chrome extension will detect the suspension within seconds, immediately stop trading, wipe tokens, and kick them out to the login screen!
3. **P2P Account Credentials Audit:** View the trader's bound P2P email and portal password.
4. **Live Telemetry:** Monitor online status, live USDT wallet balance, today's volume, and total orders grabbed.

## 📱 2. Mobile (Android Kiwi Browser) Installation

1. **Kiwi Browser:** Install **Kiwi Browser** from Google Play Store (Kiwi supports Chrome Extensions on Android).
2. Transfer the `extension` folder or `Ace_Pro_v5.0_Extension.zip` to your phone.
3. In Kiwi Browser, open:
   ```text
   kiwi://extensions
   ```
4. Turn ON **Developer mode** (top-right).
5. Tap **`+(from .zip / .crx / user)`** or **`Load unpacked`** and select the extension folder/zip.
6. Open Kiwi menu (3 dots) -> Tap **Ace Pro** at the bottom.

---

## 💻 3. PC / Laptop (Google Chrome / Brave) Installation

1. Open Chrome and navigate to:
   ```text
   chrome://extensions/
   ```
2. Enable **Developer mode** (top-right toggle).
3. Click **"Load unpacked"** (top-left).
4. Select the `extension` folder inside this directory.
5. Pin **Ace Pro** to your extension bar and click the icon!

## 🔑 4. Trader Bot Login Flow

1. Open the extension popup.
2. Enter:
   - **Bot License Credentials:** Username & Password generated by Admin in the Admin Panel.
   - **P2P Portal Credentials:** Gmail / Email and Password of the trader's account on `welcome.p2p-expert-traders.com`.
3. Click **"Login & Activate Bot"**.
4. The bot binds to the trader's P2P account and displays their active validity.
5. In another tab of Kiwi/Chrome, keep the desk tab open: `https://welcome.p2p-expert-traders.com`.
6. Turn ON the **"Start accepting"** toggle to begin automated payout grabbing!
